## Web / RWD 共用 UI 規格

<a id="已確認-web-傳遞模式與共用執行環境"></a>
<a id="confirmed-web-delivery-model-and-shared-runtime"></a>
### Web 傳遞模式與共用執行環境（2026-10-01 PM 決議）

- HINE 是供 Chrome／Edge 桌面版及 Android Chrome 手機瀏覽器驗收的單一 Web 應用程式；不做原生應用程式或 PWA。
- 前端 A 與前端 B 是同一 Web 體驗的功能區域，共用一個 SessionContext 負責者（FB）、公開 REST API、WSS 事件／模型，以及一個應用程式範圍 WSS 負責者（FA）。
- 同一瀏覽器設定檔僅一個可操作聊天分頁；Web Lock `hine-session` 在認證前取得並持有。未取得者顯示「聊天已在另一個分頁開啟」，不認證、不連線。版面重排不建立另一個登入／工作階段、WSS、SyncCursor 或業務 API。

<a id="提案-響應式頁面與共用元件規則"></a>
<a id="proposed-responsive-page-and-shared-component-rules"></a>
### 響應式頁面與共用元件規則（2026-10-01 PM 決議）

只有一個斷點 768 CSS px：`w < 768` 為窄版，`w >= 768` 為寬版。

| 可用 Web 視窗寬度 | 版面區間 |
|---|---|
| `w < 768` CSS px | 窄版 |
| `w >= 768` CSS px | 寬版 |

UI 路由為 `/`、`/login`、`/register`、`/contacts`、`/chats`、`/chats/{conversation_id}`、`/profile` 與 `/groups/{conversation_id}/manage`。這些路由不新增後端路由或 API。登入／註冊為公開頁；受保護路由等待授權，授權前不揭露受保護內容。登入後只返回已授權的請求 UI 路由。瀏覽器上一頁／下一頁還原 UI 路由／狀態；深層連結與重新整理進入相同守衛流程。圖片／檔案預覽是已授權頁面內介面，不新增路由。

<a id="rwd-root-route"></a>**根路徑 `/`：** `/` 不是內容頁，只負責導向，不新增後端路由或 API，並納入 DO 頁面路由回退允許清單。初始化中顯示載入狀態、不渲染受保護內容；未登入時以 replace 導向 `/login`，已登入時以 replace 導向 `/chats`。重新整理／直接開啟都重跑判定；判定失敗依 FB 錯誤處理顯示，不猜測登入狀態。

| 頁面類別 | 窄版（`w < 768`） | 寬版（`w >= 768`） |
|---|---|---|
| 登入與註冊 | 單欄表單，送出操作可見 | 置中表單，主要操作區清晰 |
| 聯絡人／目錄 | 清單與詳細資料分頁切換，提供返回 | 導覽與聯絡人清單／詳細資料並列 |
| 聊天清單／對話串 | 清單與聊天室分頁切換，提供返回清單操作 | 對話清單與聊天室雙欄 |
| 個人檔案／頭像 | 單欄表單，含預覽與儲存／取消 | 導覽旁的個人檔案表單與頭像預覽 |
| 群組管理 | 區段與詳細資料分頁切換，提供返回 | 導覽與群組管理內容並列 |
| 群組資訊 | 抽屜／對話框 | 同一抽屜／對話框 |
| 圖片／檔案 | 全螢幕檢視器，可開啟詳細資料抽屜 | 受限尺寸檢視器，可開啟詳細資料抽屜 |

- **共用表單與控制項：** 每個欄位皆有程式可識別及可見的標籤。驗證訊息指出欄位與修正方式；提交無效資料時焦點移至第一個無效欄位。提交、停用、載入、成功、空白與錯誤狀態彼此區分。空白／錯誤介面提供適當下一步；提示不阻斷操作、以無障礙方式公告，且不取代欄內驗證或重要復原機制。
- **觸控、焦點與覆蓋層：** 最小觸控目標為候選 44 CSS px（未列入 2026-10-01 決議，仍為候選值）；焦點可見、Tab 順序合理。模態視窗／抽屜僅模態期間限制焦點；Escape 關閉最上層可關閉覆蓋層，關閉後焦點返回觸發項目，路由變更後焦點移至新頁標題。
- **內容界限：** 必要時文字使用 `overflow-wrap:anywhere`；媒體、中繼資料與檔名設定 `max-width:100%`，不得撐寬頁面或對話串；簽署儲存網址不得以 UI 文字顯示。
- <a id="rwd-local-filter"></a>**搜尋／篩選：** 聯絡人與聊天清單中的搜尋只對本機已載入項目（A08 聯絡人摘要、A11 對話摘要）依顯示名稱或對話標題做文字篩選，不呼叫 A07、不送伺服器查詢，也不代表已搜尋未載入頁面；尚有下一頁時標示「只篩選已載入項目」並可繼續載入。新增聯絡人仍用 A07 已知公開 ID 查詢；關鍵字找人不在範圍。
- **導覽與返回：** 列出的 UI 路由為頁面路由回退允許清單；伺服器對 UI 路徑回傳同一 Web 應用程式入口。瀏覽器歷史反映路由進入、選取聊天及開啟／關閉預覽；不得攔截一般上一頁／下一頁。路由變更不建立另一工作階段、WSS、SyncCursor 或業務 API。


<a id="提案-fa-聊天輸入捲動與已讀行為"></a>
<a id="proposed-fa-chat-input-scroll-and-read-behavior"></a>
### FA 聊天輸入、捲動與已讀行為（2026-10-01 PM 決議）

- 鍵盤判別不依寬度。實體鍵盤 Enter 送出、Shift+Enter 換行；軟體鍵盤 Enter 換行、送出按鈕提交。`compositionstart`／`event.isComposing` 啟用 IME 防誤送保護，`compositionend` 解除；組字期間 Enter 絕不提交。
- <a id="rwd-keyboard"></a>**鍵盤類型判別：** 依輸入能力訊號（例如 `(any-pointer: fine)`、`(any-hover: hover)`、撰寫區聚焦時 `visualViewport` 是否因虛擬鍵盤縮小），不以視窗寬度或版面區間推定。無法判別或訊號矛盾時採保守行為：Enter 換行、送出按鈕常時可見，並支援 Ctrl+Enter／⌘+Enter；IME 保護不變。
- 追蹤 `visualViewport` 高度／偏移，使撰寫區保持在虛擬鍵盤上方且不遺失草稿、對話串或焦點；調整大小／方向時保留各對話草稿與待處理 C1。
- 以 `message_id` 與像素偏移保存閱讀錨點；調整大小／方向及前置載入舊歷史時維持位置。瀏覽歷史不強制捲至底部；僅在使用者距離底部不超過候選 48 CSS px（未列入 2026-10-01 決議，仍為候選值）時自動跟隨新訊息，否則保留閱讀位置並提供「新訊息提示」與「跳至最新」。新訊息提示可為本機訊息數，不等於聊天清單 `unread_count`，也不代表已讀（見 [C14](../contracts/interface-contract.md#unread-count)）。
- <a id="rwd-read-rule"></a>**已讀判定：** W08 在已收訊息及其識別資訊完成本機持久保存後送出。W09 僅對他人所發、尚未回報已讀訊息送出；自己的訊息不送 W09。
  - **觀察單位：** 每則訊息內容元素（泡泡，含文字、附件預覽及標題列），以 CSS px 計。
  - **有效可視區 V：** 對話串捲動容器與 `visualViewport` 可視矩形交集，再扣除覆蓋其上的固定元素（頂列、撰寫區、非模態面板），寬 `Vw`、高 `Vh`；虛擬鍵盤遮蔽部分自然排除。
  - **門檻：** 泡泡寬 `Bw`、高 `Bh`，`I` 為泡泡與 V 交集面積；分母為最大可能交集 `Imax = min(Bw, Vw) × min(Bh, Vh)`，可見比例 `I ÷ Imax` 至少 50%。
  - **語意與時間：** 門檻與前提連續成立 500 ms 才送 W09；任一前提中斷即歸零。代表符合畫面可見條件，不代表讀完全文；超長訊息以最大可能交集計。
  - **前提：** `document.visibilityState === "visible"`；訊息對話是目前路由且正在顯示；沒有模態預覽／對話框／模態抽屜覆蓋。只開啟對話、摘要顯示、收到通知或送 W08 都不代表已讀。正反案例見 [REQ-20 詳細驗收](../testing/acceptance-matrix.md#req-20-detail)。

### Web Push 範圍

**本版範圍外（2026-10-01 PM 決議）：** Web Push 與 iOS／Android 原生推播均不納入本版。不選供應商、不建立 Service Worker、不管理瀏覽器訂閱、不整合 APNs／FCM。保留開啟網頁時 WSS 即時訊息、聊天內提示與查詢後更新未讀徽章；關閉網頁後不保證通知。A23／A24 與 `DeviceTokenStatus.platform` 不構成 Web Push 契約；不要求推播 worker 或金鑰。
