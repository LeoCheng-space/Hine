# HINE 文件變更紀錄

## HINE-IC-0.4 — 獨立文件提案，待批准

- 現行提案文件分為[獨立共用介面契約](contracts/interface-contract.md)、[Web/RWD 規格](ui/web-rwd.md)、[`prd/`](prd/) 下六份獨立角色 PRD、獨立[驗收矩陣](testing/acceptance-matrix.md)及中央[待決策事項登錄表](decisions.md)。
- 較早的整合版 [HINE-IC-0.4 契約](HINE-IC-0.4-contract.md)與[六角色 PRD](HINE-IC-0.4-role-prds.md)僅作歷史整合來源保存，不具共同權威性，也不是現行導覽目標。
- 新增可點選的[角色與主題文件地圖](README.md)，串連角色職責、契約查找、驗收及待決政策。
- 新增共用 Web 響應式（RWD）文件並於角色 PRD 中互相連結。文件說明已確認的單一 Web app 交付基線，也明確將候選版面與互動規則標示為待批准；不推定原生 App 或 PWA 範圍。
- 拆分導覽讓角色職責、共用契約查找及待決政策更容易查閱；標準需求列與 REQ-19–REQ-22 Web 詳細驗收已收錄於獨立驗收矩陣。
- 補齊六角色共 43 項功能卡的具名 REQ、實際 API／事件／內部操作與協作功能章節連結；FB-06 直接指向未核准的 Web Push 決策，與既有原生 A23/A24 契約區分。共用契約僅增加現有內部操作的錨點，不改介面語義。
- 新增[系統架構](architecture/README.md)：元件與責任邊界、資料權威、識別碼與排序、連線／傳送／群組事件／附件／推播流程、部署拓樸、失效模式、安全、可觀測性、交付與容量驗證。另於[待決策事項](decisions.md)登錄 GCP 執行環境、技術棧、api／realtime 部署單元、REST 寫入後的即時通知路徑與負載測試工具等架構決策。本次未修訂 A01–A25、W01–W22 或任何契約語意。
- 本次文件地圖與內容拆分未修訂 A01–A25、W01–W22 名稱／ID、標準資料、ACK/Cursor/sync 語意；不代表已批准、實作、部署或完成產品測試。
