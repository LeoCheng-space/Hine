# 後端共用模組（可選）

此目錄為**可選**的後端共用程式碼位置，例如同語言模組之間的型別、工具、常數或驗證輔助函式。是否使用由相關模組負責人決定（2026-10-01 PM 決議）。

- 不是整合的必要條件：`api` 與 `realtime` 可以使用不同語言，不要求共用此目錄的原始碼、型別或 ORM。
- 跨語言整合的共同依據是[共用介面契約](../../docs/contracts/interface-contract.md)、Schema 與測試樣例，以及既定的 HTTP／JSON 與 WebSocket 格式。
- 若同語言模組選擇在此共用程式碼，其行為仍以共用介面契約為準，不得在此另訂 API、事件或資料格式。
